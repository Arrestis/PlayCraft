PlayCraft is a free, open-source DVD, CD and Blu-ray player for Windows, macOS and Linux
(GPL-3.0).

## What's new in 0.2.0

- DVD and Blu-ray disc menus, controlled with the mouse, the keyboard or the remote.
- A pop-out remote styled like a Blu-ray remote, with resizing and a mini mode. It can sit
  outside the PlayCraft window, and its volume keys can control the computer's own volume.
- Installers for every system: Windows (.msi for x64, ARM64 and x86), macOS (.dmg) and
  Linux (AppImage, .deb, .rpm, Arch package and .tar.gz).
- An activity log, a user guide, a changelog and the full GPL-3.0 licence.
- Fixes: menu buttons staying lit or staying on the picture during playback, and a freeze
  when choosing some menu buttons.

The full list of changes is in [CHANGELOG.md](https://github.com/Arrestis/PlayCraft/blob/main/CHANGELOG.md).
